# Delivery pop-up (Where + When)

**Modal keys:** `when`, `addr`, `slot` · **State:** `S.dmode`, `S.day`, `S.slot`, `S.addrs`

- **Where:** postcode or saved street with *Add address* / *Change*.
  - First address: map preview, "Use my current location", type (Home, Office, Other), street, postcode (prefilled), city, notes for the driver.
- **When:** Fastest, Bundled delivery ("Outside peak hours, so we can bundle deliveries on your street."), and *Choose a time ›* which opens the slot grid. Every option is free on the first order.
- The time starts empty. "Your time is held once you place the order."
